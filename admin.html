Two things to know

This is a bookmark, not a login. The site is static files with no server, so there is nothing that can check a password before sending a page. Anyone with the exact address can open any of these. None of them store client data, they only format what is typed into them, so there is nothing sitting here to be taken.

Three of the four are meant for clients. The agreement, music plan and extras sheet are all linked from the booking page on purpose, because the client is the one who fills them in. Putting those behind a sign-in only you can pass would stop them working. Only the invoice page is yours alone.
